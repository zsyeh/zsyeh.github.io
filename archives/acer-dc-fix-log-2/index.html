前言

我的 Acer Nitro 5（2023 款暗影骑士·擎，AN515-58）最近出现了一个非常烦人的问题。

最开始只是偶尔听到电源蜂鸣器报警，后来发展到：

  • 轻轻碰一下 DC 插头就掉电
  • 插头旋转一点点立即断电
  • 甚至继续向里面压插头也会掉电

起初一直以为是充电器接触不良，但后来逐渐确认，真正损坏的是 DC 母座内部弹片。

于是开始了这次维修。

故障分析

最开始观察到几个现象：

  • Windows 电源状态偶尔切换
  • Acer 电源蜂鸣器不断报警
  • 插头已经插到底
  • 左右旋转立即掉电
  • 插头继续向里面施加轴向压力也可能掉电

由于掉电完全和机械动作有关，因此首先排除：

  • Windows 系统
  • 电池
  • BIOS
  • 软件

基本可以确定：

这是一个纯机械接触故障。

拆机检查

拆开后盖以后可以看到：

AN515-58 的 DC 电源接口 不是线束式，而是直接焊接在主板上的。

意味着：

  • 无法直接更换 DC 线束
  • 必须拆主板
  • 必须进行拆焊

确认故障

继续检查 DC 母座。

发现：

内部负责夹紧插头的金属弹片已经完全塌陷。

插头虽然可以插到底，但是已经没有足够的接触压力。

因此：

稍微旋转一下，

接触立即断开。

最终确认：

故障并不是充电器，而是 DC 母座本身。

购买新 DC 母座

淘宝可以买到兼容 AN515-58 的 DC 母座。

需要注意：

不要只搜索：

5.5×1.7

因为很多 DC Jack 虽然尺寸相同，

但是：

  • 焊脚位置不同
  • 外壳尺寸不同
  • 高度不同

最好直接购买：

AN515-58 / N22C1 对应型号

第一次拆焊

都怪hsm不早点邮寄 害得我拆电脑的时候只能用tb10元劣质电赛级烙铁

结果：

无论怎么加热，

原厂焊锡几乎完全不融。

我以为是铁焊呢

AN515-58 的 DC 外壳固定脚直接连接主板 GND 大铜皮。

普通烙铁热容量完全不够。

看起来像：

焊锡死活不化。

实际上：

热量全部被主板吸走了。

更换更好的焊台

后来等快递换了更好的焊台。

同时补充：

63/37 有铅焊锡

让原厂无铅焊锡混合降低熔点。

随后：

利用吸锡器完成清孔。

整个 DC Jack 顺利拆下。

焊接新的 DC 母座

新的 DC Jack 焊接比较顺利。

完成后：

电脑终于能够重新识别适配器。

不过新的问题马上出现。

Windows 黑屏

第一次开机时，Windows 出现：

INACCESSIBLE_BOOT_DEVICE

不过在黑屏错误码 就说明 Windows 内核开始加载。这说明机器已经通过基本硬件初始化，主板大概率没有因为拆焊而损坏，问题更像是系统盘的存储控制器配置发生了变化。

因此我第一时间想到 Intel VMD。

进入 BIOS 检查后，果然发现 VMD 被关闭了。重新开启 Intel VMD 后，Windows 立即恢复正常启动。

这也验证了之前的判断：

主板本身没有问题，蓝屏只是 BIOS 中的存储控制器设置发生了变化。

第二个问题：20 分钟后停止充电

真正让我头疼的是：

电脑能够正常开机。

能够正常充电。

但是：

大约二十分钟以后，

突然停止充电。

最开始怀疑：

  • MOS 管被烫坏
  • 助焊剂受热短路
  • 焊锡质量问题

甚至怀疑：

自己把主板修坏了。

后来逐步排查：

  • DC 正负极阻值约 73kΩ
  • 没有明显短路
  • DC 插头没有异常发热

说明：

不是短路。

真正原因

最后重新检查焊点。

发现：

GND 焊点虽然外观看起来已经焊好。

实际上：

接触并不好。

于是重新补焊：

所有 GND 固定脚。

补焊完成以后：

问题立即消失。

电脑已经连续运行四十分钟以上，

没有再次掉充电。

为什么 GND 会导致这种现象？

很多人容易认为：

DC 正极才最重要。

实际上：

整个回流电流全部经过 GND。

如果：

GND 接触电阻稍微偏大，

就会：

  • 局部发热
  • 电压下降
  • 充电管理芯片认为输入异常

于是：

直接停止充电。

因此：

即使正极焊得很好，

GND 焊接不好，

整个 DC 输入仍然无法正常工作。

本次维修总结

整个维修过程中，一共踩了几个坑。

1. 不要迷信普通烙铁

DC Jack 属于大铜皮连接器。

普通几十元烙铁基本拆不下来。

建议：

  • 大功率焊台
  • 大马蹄头
  • 足够助焊剂
  • 63/37 焊锡

2. 不要看到 Windows 蓝屏就认为主板坏了

我的蓝屏： INACCESSIBLE_BOOT_DEVICE 真正原因只是：

BIOS 的 Intel VMD 被关闭。

重新打开即可。

3. GND 焊点同样重要

很多人只关注正极。

实际上：

负极承担整个充电回路。

任何一个 GND 固定脚接触不好，

都可能导致：

  • 间歇掉电
  • 停止充电
  • 电压异常

4. 不要只凭感觉判断

整个维修过程中：

我一度怀疑：

  • MOS 管坏了
  • 助焊剂短路
  • 焊锡有问题

最终证明：

真正的问题只是：

GND 焊接不充分。

最终结果

目前：

  • ✅ 插头稳定
  • ✅ 不再旋转掉电
  • ✅ Windows 正常启动
  • ✅ 连续运行四十分钟以上正常充电
  • ✅ DC 插头温度正常
  • ✅ 无异常蜂鸣

这次维修总算顺利结束。

后记

整个维修过程中最大的收获，并不是成功更换了一个 DC 母座。

而是更加深刻地理解了：

排查故障时，不应该不断猜测，而应该让每一步测试都排除一种可能性。

很多时候，看似复杂的问题，最终真正的原因反而十分简单。
