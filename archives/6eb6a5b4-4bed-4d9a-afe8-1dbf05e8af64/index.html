1.2.1 通道定义 五个独立通道中的每一个都包含一组信息信号，并使用双向的 VALID 和 READY 握手机制。

信息源使用 VALID 信号来表明通道上何时有有效的数据或控制信息。目标端使用 READY 信号来表明它何时可以接收数据。读数据通道和写数据通道都还包含一个 LAST 信号，用于指示事务中的最后一个数据项何时正在传输 这些通道是 AXI 协议的核心分类，用于处理读写事务：

写地址通道 (Write address channel)：用于传输写操作的地址和控制信息 写数据通道 (Write data channel)：用于将写数据从主设备 (master) 传输到从设备 (slave) 写响应通道 (Write response channel)：从设备使用此通道向主设备发回写操作完成的信号 读地址通道 (Read address channel)：用于传输读操作的地址和控制信息 读数据通道 (Read data channel)：用于将读数据和任何读响应信息从从设备传回主设备

通道握手

传输 (Transfer) 仅在 VALID 和 READY 信号同时为高电平时发生 。 信息源 (source) 控制 VALID 信号。信息源使用 VALID 信号来表明数据或控制信息何时可用 目标端 (destination) 控制 READY 信号。目标端使用 READY 信号来表明它何时可以接收数据或控制信息 。
